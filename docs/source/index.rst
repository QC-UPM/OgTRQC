Supplementary material and figures
==================================

This repository generates supplementary material for **Proton Transport and
Polarization Relaxation in Hx–NdNiO3: Literature-Constrained Reduced Models and
a Recoverability Diagnostic**. The manuscript and original notebooks remain
external. Generation uses explicit, hash-verified numeric inputs.
